# Camon

Multi-camera NVR with real-time motion and object analytics. Camon streams RTSP
cameras into a memory buffer, records motion and object events, and embeds its
web interface in the Home Assistant sidebar through ingress.

Camon uses the same `camon.toml` configuration as a native installation. See
the **Documentation** tab after installation or the
[Camon project](https://github.com/nsg/camon) for the complete configuration
reference. The Home Assistant app is available for `amd64` systems only.
